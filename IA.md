# Uso de Inteligencia Artificial — BookSpace

## Herramienta utilizada

Durante el desarrollo de BookSpace se utilizó **ChatGPT (OpenAI)** como herramienta de apoyo para resolver dudas técnicas, consultar ejemplos de código y solucionar errores.

## Principales consultas realizadas

Algunos ejemplos resumidos de las consultas realizadas fueron:

- ¿Cómo consumir los datos de Open Library API utilizando Angular?
- ¿Cómo organizar la navegación por pestañas en Ionic?
- ¿Cómo guardar información mediante localStorage?
- ¿Cómo implementar reseñas y calificaciones de libros?
- ¿Cómo solucionar errores de compilación y pruebas unitarias?

## Partes desarrolladas con asistencia de IA

Se utilizó asistencia de IA en la implementación y revisión de servicios, componentes, almacenamiento local, navegación e integración de **Open Library API** para la búsqueda y consulta de información de libros.

## Modificaciones y correcciones

Durante el desarrollo se realizaron ajustes en la interfaz, correcciones en la actualización de los libros de la biblioteca y modificaciones en las pruebas unitarias.

Los cambios se comprobaron mediante pruebas manuales y comandos como `npm run build` y `npm run test:unit`.

## Conclusión

ChatGPT fue utilizado como recurso complementario de aprendizaje y apoyo técnico durante el desarrollo del proyecto.

Las funcionalidades se integraron y verificaron progresivamente en la aplicación.
